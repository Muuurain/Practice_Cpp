### 前提说明
`std::queue` 是**容器适配器**，底层默认基于 `deque` 实现，遵循**先进先出（FIFO）** 规则，仅开放队头、队尾操作，无随机访问、无中间插入删除，所有核心操作均为常数时间：
- 所有队头队尾相关操作（入队、出队、访问元素）均为 $O(1)$；
- 拷贝、赋值等涉及全元素操作复杂度与元素个数成正比；
- 标注核心为「日常关注的最坏/平均复杂度」，特殊场景备注说明。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `queue()`                     | O(1)                   | O(1)     | 初始化底层容器，无元素分配/拷贝                                              |
|                    | `queue(const queue& other)`   | O(n)                   | O(n)     | 拷贝底层容器所有n个元素，全量复制                                            |
|                    | `operator=`（赋值queue）      | O(n)                   | O(n)     | 清空原队列，拷贝赋值队列的所有元素，全量复制                                 |
| 长度与容量操作     | `size()`                      | O(1)                   | O(1)     | 直接返回底层容器的元素个数，无计算/遍历                                      |
|                    | `empty()`                     | O(1)                   | O(1)     | 判断队列内是否无元素，常数时间判断                                             |
| 元素访问           | `front()`                     | O(1)                   | O(1)     | 直接访问底层容器头部元素，无遍历/偏移                                        |
|                    | `back()`                      | O(1)                   | O(1)     | 直接访问底层容器尾部元素，无遍历/偏移                                        |
| 入队与出队操作     | `push(const T& val)`          | O(1)                   | O(1)     | 在队尾插入元素，仅修改指针/成员变量                                 |
|                    | `emplace(args)`               | O(1)                   | O(1)     | 队尾原地构造元素，效率高于push，常数时间                                      |
|                    | `pop()`                       | O(1)                   | O(1)     | 删除队头元素，仅修改指针/成员变量，无数据拷贝                        |
| 容器操作           | `swap(queue& other)`          | O(1)                   | O(1)     | 交换两个queue的底层容器，仅交换内部指针，无元素拷贝                          |

### 关键总结
1. **O(1) 操作**：构造空队列、`size`/`empty`、`front`/`back` 访问元素、`push`/`emplace`/`pop` 操作、`swap` 交换；
2. **O(n) 操作**：拷贝构造、赋值运算符，需复制队列中全部n个元素；
3. **核心特性**：仅支持队尾入队、队头出队，无迭代器、无随机访问、无中间操作，底层容器扩容开销由底层实现承担，对外表现仍为O(1)；
4. **使用限制**：无法遍历队列内元素，如需遍历需先弹出所有元素或改用其他容器。
