### 前提说明
`std::deque` 底层基于**分段连续内存**实现的双端队列，支持双端常数时间操作、随机访问，中间插入删除需移动元素，时间复杂度区分操作位置：
- 双端增删、随机访问、容量查询均为 $O(1)$；
- 中间插入/删除、全量拷贝为 $O(n)$；
- 标注核心为「日常关注的最坏/平均复杂度」，特殊场景备注说明。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `deque()`                     | O(1)                   | O(1)     | 初始化分段内存管理结构，无元素分配/拷贝                                      |
|                    | `deque(const deque& other)`   | O(n)                   | O(n)     | 拷贝所有n个元素，全量复制到新的分段内存中                                    |
|                    | `operator=`（赋值deque）      | O(n)                   | O(n)     | 清空原容器，拷贝赋值对象所有元素，全量复制                                   |
|                    | `assign(n, val)`              | O(n)                   | O(n)     | 批量赋值n个相同元素，覆盖原有数据                                            |
| 长度与容量操作     | `size()`                      | O(1)                   | O(1)     | 直接返回元素个数，无计算/遍历                                                |
|                    | `empty()`                     | O(1)                   | O(1)     | 判断容器是否为空，常数时间判断                                               |
|                    | `resize(n)`                   | O(n)                   | O(n)     | 调整容器大小，新增/删除元素，线性时间                                        |
|                    | `clear()`                     | O(n)                   | O(n)     | 清空所有元素，销毁分段内存节点                                               |
| 元素访问           | `operator[](pos)`              | O(1)                   | O(1)     | 随机访问指定位置元素，无越界检查                                             |
|                    | `at(pos)`                     | O(1)                   | O(1)     | 随机访问+越界检查，非法下标抛异常                                            |
|                    | `front()`                     | O(1)                   | O(1)     | 直接访问头部元素，常数时间                                                   |
|                    | `back()`                      | O(1)                   | O(1)     | 直接访问尾部元素，常数时间                                                   |
| 双端操作           | `push_back(val)`              | O(1)                   | O(1)     | 尾部插入元素，无需扩容/移动元素                                              |
|                    | `pop_back()`                  | O(1)                   | O(1)     | 删除尾部元素，常数时间                                                       |
|                    | `push_front(val)`             | O(1)                   | O(1)     | 头部插入元素，双端队列核心特性                                              |
|                    | `pop_front()`                 | O(1)                   | O(1)     | 删除头部元素，常数时间                                                       |
| 插入与删除         | `insert(it, val)`             | O(n)                   | O(1)     | 迭代器位置插入，两端O(1)，中间需移动元素O(n)                                 |
|                    | `erase(it)`                   | O(n)                   | O(1)     | 删除迭代器位置元素，两端O(1)，中间需移动元素O(n)                             |
| 迭代器操作         | `begin()`/`end()`             | O(1)                   | O(1)     | 返回容器迭代器，常数时间                                                     |
| 容器操作           | `swap(deque& other)`          | O(1)                   | O(1)     | 交换两个deque的内存管理结构，无元素拷贝                                      |

### 关键总结
1. **O(1) 操作**：构造空容器、`size`/`empty`、随机访问`[]`/`at`、首尾访问、双端增删、`swap`交换、迭代器获取；
2. **O(n) 操作**：拷贝构造、赋值、`assign`/`resize`/`clear`、中间插入/删除、全量遍历；
3. **核心特性**：分段连续内存，兼顾vector的随机访问和list的双端高效操作，无内存碎片，中间操作效率低于双端操作；
4. **使用场景**：滑动窗口、双端BFS、需要频繁头尾操作的场景。
