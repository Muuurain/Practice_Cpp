### 前提说明
`std::vector` 底层基于**动态连续数组**实现（存储 `size`、`capacity`、底层指针），时间复杂度需区分「是否扩容」「操作位置」「最好/最坏情况」：
- 「最好情况」：无扩容、操作在末尾（仅修改成员变量/直接写入）；
- 「最坏情况」：需扩容、操作在开头（涉及数据拷贝/移动）；
- 标注核心为「日常关注的最坏/平均复杂度」，特殊场景备注说明。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `vector()`                    | O(1)                   | O(1)     | 仅初始化 `size=0`/`capacity=0`，无内存分配/拷贝                              |
|                    | `vector(size_t n)`            | O(n)                   | O(n)     | 分配n个元素空间并初始化默认值，必须遍历n次                                    |
|                    | `vector(size_t n, T val)`     | O(n)                   | O(n)     | 分配n个元素空间并填充val，必须遍历n次                                        |
|                    | `vector(const vector& other)`| O(n)                   | O(n)     | 拷贝原vector所有n个元素，全量数据拷贝                                         |
|                    | `operator=`（赋值vector）     | O(n)                   | O(n)     | 拷贝赋值对象的所有元素，全量数据拷贝                                          |
|                    | `assign(n, val)`              | O(n)                   | O(n)     | 清空原vector，创建n个新元素并赋值val，遍历n次                                |
| 长度与容量操作     | `size()`                      | O(1)                   | O(1)     | 直接返回成员变量`size`，无计算/遍历                                          |
|                    | `empty()`                     | O(1)                   | O(1)     | 仅判断`size==0`，常数时间                                                    |
|                    | `capacity()`                  | O(1)                   | O(1)     | 直接返回成员变量`capacity`                                                   |
|                    | `reserve(n)`                  | O(m)                   | O(1)     | m为新capacity（n≤当前capacity时O(1)；n>capacity时拷贝原数据，O(原size)）      |
|                    | `shrink_to_fit()`             | O(n)                   | O(n)     | 重新分配`size`大小的内存，拷贝所有元素（n为当前size）                         |
|                    | `resize(n)`                   | O(n)                   | O(1)     | n<size时删除末尾元素O(n−size)；n>size时新增元素O(n−size)；n=size时O(1)        |
|                    | `resize(n, val)`               | O(n)                   | O(1)     | 逻辑同resize(n)，新增元素赋值val，遍历次数为元素增减数                       |
|                    | `clear()`                     | O(1)                   | O(1)     | 仅将`size`置0，不释放内存/移动数据                                           |
| 元素访问           | `operator[]`                  | O(1)                   | O(1)     | 连续数组下标偏移访问，无越界检查                                             |
|                    | `at(size_t pos)`              | O(1)                   | O(1)     | 下标访问+常数时间的越界检查（`pos<size`）                                    |
|                    | `front()`/`back()`            | O(1)                   | O(1)     | 等价于`v[0]`/`v[size-1]`，直接访问首尾元素                                   |
|                    | `data()`                      | O(1)                   | O(1)     | 返回底层数组指针，无拷贝/遍历                                                |
| 尾部增删元素       | `push_back(T val)`            | O(n)                   | O(1)     | 无扩容O(1)（直接写入末尾）；扩容需拷贝原数据，O(原size)                       |
|                    | `emplace_back(args)`          | O(n)                   | O(1)     | 尾部原地构造元素，效率更高；无扩容O(1)，扩容O(原size)                        |
|                    | `pop_back()`                  | O(1)                   | O(1)     | 仅将`size-1`，无数据移动/拷贝                                                |
| 任意位置插入删除   | `insert(it, val)`             | O(n)                   | O(1)     | 需移动插入位置后所有元素O(n)；插入末尾无移动O(1)，扩容额外加O(原size)         |
|                    | `insert(it, n, val)`          | O(n+k)                 | O(k)     | k为插入元素个数；需移动后续元素O(n)，拷贝插入元素O(k)                        |
|                    | `v.insert(it, first, second)` | O(n+k)                 | O(k)     | n = 原元素数，k = 插入区间长度；插末尾仅拷贝 O (k)，插中间需移动 + 拷贝；扩容加拷贝开销 |
|                    | `emplace(it, args)`           | O(n)                   | O(1)     | 迭代器位置原地构造，同insert复杂度，插入末尾最优O(1)                         |
|                    | `erase(it)`                   | O(n)                   | O(1)     | 需移动删除位置后所有元素O(n)；删除末尾仅改size，O(1)                         |
|                    | `erase(first, last)`          | O(n)                   | O(1)     | 批量删除，移动后续元素O(n)；删除末尾区间O(1)                                |
| 容器操作           | `swap(vector& other)`         | O(1)                   | O(1)     | 仅交换`size`/`capacity`/底层指针，无数据拷贝                                 |
| 遍历与迭代器       | `begin()`/`end()`             | O(1)                   | O(1)     | 直接返回迭代器，无遍历/计算                                                  |
| 非成员函数         | `swap(vector1, vector2)`      | O(1)                   | O(1)     | 同成员函数swap，仅交换vector内部指针                                         |
|                    | 范围for遍历                  | O(n)                   | O(n)     | 遍历所有元素，时间与元素个数成正比                                           |

### 关键总结
1. **O(1) 操作**：仅访问/修改成员变量（`size`/`capacity`）、末尾操作无扩容（`push_back`/`pop_back`/`emplace_back`）、`swap`、随机访问元素、迭代器获取；
2. **O(n) 操作**：涉及全量数据拷贝/移动（构造、赋值、`resize`、开头/中间`insert`/`erase`、`shrink_to_fit`）；
3. **核心特性**：支持**随机访问**，尾部操作效率极高，中间/开头操作因数据移动效率低；
4. **扩容优化**：`reserve(n)` 预分配空间可避免频繁扩容，将尾部插入的均摊复杂度优化为O(1)。
