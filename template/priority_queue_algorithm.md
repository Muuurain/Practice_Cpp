### 前提说明
`std::priority_queue` 是**容器适配器**，底层默认基于 `vector` 实现**二叉堆**，遵循**堆顶元素优先级最高**规则，仅开放堆顶操作，核心操作依托堆调整实现，时间复杂度固定：
- 堆调整相关操作（入队、出队）均为 $O(\log n)$；
- 堆顶访问、容量查询为 $O(1)$；
- 拷贝、赋值等全元素操作复杂度与元素个数成正比；
- 标注核心为「日常关注的最坏/平均复杂度」，特殊场景备注说明。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `priority_queue()`            | O(1)                   | O(1)     | 初始化底层容器与堆规则，无元素分配/拷贝                                      |
|                    | `priority_queue(const priority_queue& other)` | O(n) | O(n) | 拷贝底层容器所有元素并重建堆，全量复制+堆构建                                |
|                    | `operator=`（赋值）           | O(n)                   | O(n)     | 清空原容器，拷贝元素并重建堆，全量复制+堆调整                               |
| 长度与容量操作     | `size()`                      | O(1)                   | O(1)     | 直接返回底层容器的元素个数，无计算/遍历                                      |
|                    | `empty()`                     | O(1)                   | O(1)     | 判断堆内是否无元素，常数时间判断                                             |
| 堆顶元素访问       | `top()`                       | O(1)                   | O(1)     | 直接访问堆顶（数组首元素），无堆调整/遍历                                    |
| 入队与出队操作     | `push(const T& val)`          | O(log n)               | O(log n) | 尾部插入元素+向上堆调整，维护堆结构                                           |
|                    | `emplace(args)`               | O(log n)               | O(log n) | 堆底原地构造元素+向上堆调整，效率更高                                        |
|                    | `pop()`                       | O(log n)               | O(log n) | 堆顶与堆底交换+删除尾元素+向下堆调整，维护堆结构                             |
| 容器操作           | `swap(priority_queue& other)` | O(1)                   | O(1)     | 交换两个优先队列的底层容器，仅交换内部指针，无元素拷贝/堆调整                |

### 关键总结
1. **O(1) 操作**：构造空队列、`size`/`empty`、`top` 访问堆顶、`swap` 交换；
2. **O(log n) 操作**：`push`/`emplace` 入队、`pop` 出队，核心堆调整操作；
3. **O(n) 操作**：拷贝构造、赋值运算符，需复制全部元素并重建二叉堆；
4. **核心特性**：默认大顶堆，可自定义排序规则改为小顶堆，仅支持堆顶操作，无迭代器、无随机访问、无中间元素操作。
