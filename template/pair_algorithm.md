### 前提说明
`std::pair` 是固定大小的**二元组模板**，用于存储两个关联值（可同类型/不同类型），仅包含 `first`、`second` 两个公有成员变量，无动态内存分配、无扩容、无复杂数据结构，所有操作均为常数时间：
- 所有构造、赋值、访问、比较、交换操作均为 $O(1)$；
- 标注核心为「日常关注的最坏/平均复杂度」，特殊场景备注说明。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `pair()`                      | O(1)                   | O(1)     | 默认构造，初始化两个成员为默认值，无内存分配                                 |
|                    | `pair(const T1& a, const T2& b)` | O(1)                | O(1)     | 用两个值直接初始化，拷贝两个成员变量                                         |
|                    | `pair(const pair& other)`     | O(1)                   | O(1)     | 拷贝构造，复制另一个pair的两个成员                                           |
|                    | `operator=`（赋值pair）       | O(1)                   | O(1)     | 赋值运算符，复制两个成员变量，全量O(1)                                       |
| 成员访问           | `p.first`                     | O(1)                   | O(1)     | 直接访问第一个成员变量，公有成员无封装                                       |
|                    | `p.second`                    | O(1)                   | O(1)     | 直接访问第二个成员变量，公有成员无封装                                       |
| 比较操作           | `operator==/!=`               | O(1)                   | O(1)     | 依次比较两个成员，常数时间判断                                              |
|                    | `operator</>/<=/>=`           | O(1)                   | O(1)     | 字典序比较：先比first，再比second                                           |
| 交换操作           | `swap(pair& other)`           | O(1)                   | O(1)     | 交换两个pair的成员变量，无数据拷贝                                           |
| 非成员函数         | `make_pair(a,b)`              | O(1)                   | O(1)     | 快速创建pair对象，自动推导类型                                               |
|                    | `swap(p1,p2)`                 | O(1)                   | O(1)     | 全局交换函数，等价于成员swap                                                |

### 关键总结
1. **O(1) 操作**：所有构造、赋值、成员访问、比较、交换、创建操作，pair无任何线性时间操作；
2. **核心特性**：轻量级二元组，无内存开销、无复杂逻辑，支持默认排序，是算法竞赛存储坐标、边、键值对的最常用工具；
3. **使用场景**：替代简单结构体、配合map/vector使用、多关键字排序、存储二元数据。
