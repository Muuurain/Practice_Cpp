### 前提说明
`std::list` 底层基于**双向循环链表**实现，每个元素为独立链表节点，无连续内存空间、无 `capacity` 容量概念，**不支持随机访问**，时间复杂度核心特征：
- 「最好情况」：头尾插入/删除、访问首尾元素、交换容器、清空容器等常数时间操作；
- 「最坏情况」：遍历全链表、排序、按值查找/删除、指定位置插入/删除（需先遍历迭代器到目标位置）；
- 标注核心为「日常关注的最坏/平均复杂度」，特殊场景备注说明。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `list()`                      | O(1)                   | O(1)     | 仅初始化链表头节点，无内存分配/元素拷贝                                      |
|                    | `list(size_t n, T val)`       | O(n)                   | O(n)     | 创建n个链表节点并赋值val，需遍历构造n个节点                                  |
|                    | `list(const list& other)`     | O(n)                   | O(n)     | 拷贝原链表所有n个节点，逐个复制数据                                          |
|                    | `operator=`（赋值list）| O(n)                   | O(n)     | 清空原链表并拷贝赋值链表所有n个节点                                          |
|                    | `assign(n, val)`              | O(n)                   | O(n)     | 清空原链表，创建n个新节点并赋值val，遍历n次                                  |
| 长度与容量操作     | `size()`                      | O(1)                   | O(1)     | 直接返回成员变量size，C++11后标准保证常数时间                                |
|                    | `empty()`                     | O(1)                   | O(1)     | 仅判断size==0，常数时间判断                                                  |
|                    | `resize(n)`                   | O(n)                   | O(1)     | n<size时删除末尾节点O(n−size)；n>size时新增节点O(n−size)；n=size时O(1)        |
|                    | `resize(n, val)`               | O(n)                   | O(1)     | 逻辑同resize(n)，新增节点赋值val，遍历次数为节点增减数                       |
|                    | `clear()`                     | O(n)                   | O(n)     | 销毁链表所有n个节点，释放内存                                                |
| 元素访问           | `front()`                     | O(1)                   | O(1)     | 直接访问头节点，无遍历/偏移                                                  |
|                    | `back()`                      | O(1)                   | O(1)     | 直接访问尾节点，无遍历/偏移                                                  |
|                    | 迭代器遍历访问                | O(n)                   | O(1)     | 访问第k个元素需从头遍历k次，无随机访问能力                                  |
| 插入元素           | `push_front(val)`             | O(1)                   | O(1)     | 头部新建节点，修改指针指向，无遍历/拷贝                                      |
|                    | `push_back(val)`              | O(1)                   | O(1)     | 尾部新建节点，修改指针指向，无遍历/拷贝                                      |
|                    | `emplace_front(args)`         | O(1)                   | O(1)     | 头部原地构造节点，效率高于push_front，常数时间                               |
|                    | `emplace_back(args)`          | O(1)                   | O(1)     | 尾部原地构造节点，效率高于push_back，常数时间                                |
|                    | `insert(it, val)`             | O(1)                   | O(1)     | 迭代器已指向目标位置，仅修改指针；迭代器未定位时需先遍历O(k)（k为位置序号）|
|                    | `insert(it, n, val)`          | O(n)                   | O(n)     | 迭代器定位后插入n个节点，遍历n次构造节点                                     |
| 删除元素           | `pop_front()`                 | O(1)                   | O(1)     | 删除头节点，修改指针指向，无遍历                                             |
|                    | `pop_back()`                  | O(1)                   | O(1)     | 删除尾节点，修改指针指向，无遍历                                             |
|                    | `erase(it)`                   | O(1)                   | O(1)     | 迭代器已指向目标节点，仅修改指针；迭代器未定位时需先遍历O(k)                 |
|                    | `remove(val)`                 | O(n)                   | O(1)     | 遍历全链表删除所有值为val的节点；无匹配节点时O(1)                             |
|                    | `remove_if(cond)`             | O(n)                   | O(1)     | 遍历全链表按条件删除节点；无满足条件节点时O(1)                               |
| 拼接与合并         | `splice(it, other)`           | O(1)                   | O(1)     | 仅修改链表指针，将other链表整体拼接，无节点拷贝/遍历，other清空               |
|                    | `splice(it, other, it_other)`  | O(1)                   | O(1)     | 拼接单个节点，仅修改指针指向                                                 |
|                    | `merge(other)`                | O(n+m)                 | O(n+m)   | 合并两个有序链表，n/m为两链表长度，逐个比较节点合并                          |
| 排序与去重         | `sort()`                      | O(n log n)             | O(n log n) | 底层为归并排序，无数组随机访问，只能链表排序                                |
|                    | `sort(comp)`                  | O(n log n)             | O(n log n) | 自定义比较规则的归并排序                                                    |
|                    | `unique()`                    | O(n)                   | O(1)     | 遍历链表删除连续重复节点；无重复节点时O(1)，需先排序才有效                   |
|                    | `unique(comp)`                | O(n)                   | O(1)     | 自定义规则去重，遍历全链表判断连续节点                                       |
| 反转与交换         | `reverse()`                   | O(n)                   | O(n)     | 遍历全链表反转节点指针指向                                                  |
|                    | `swap(list& other)`           | O(1)                   | O(1)     | 仅交换链表头节点、size等成员变量，无节点拷贝/遍历                            |
| 非成员函数         | `swap(list1, list2)`          | O(1)                   | O(1)     | 同成员函数swap，仅交换链表内部指针                                           |
|                    | 范围for遍历                  | O(n)                   | O(n)     | 底层通过迭代器遍历全链表所有节点                                             |

### 关键总结
1. **O(1) 操作**：头尾访问、头尾插入/删除、迭代器定位后插入/删除、`splice`拼接、`swap`交换、`empty()`/`size()`；
2. **O(n) 操作**：构造/赋值/清空、`resize`、`remove`/`remove_if`、`unique`、`reverse`、全链表遍历；
3. **O(n log n) 操作**：链表专属`sort`排序，为list最高复杂度核心操作；
4. **核心特性**：无连续内存因此无扩容开销，中间插入/删除仅需修改指针（迭代器定位后），但无随机访问能力，访问非首尾元素必须遍历。
