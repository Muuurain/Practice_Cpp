### 前提说明
`std::string` 底层基于**动态连续字符数组**实现（存储 `size`、`capacity`、底层指针），时间复杂度需区分「是否扩容」「操作位置」「最好/最坏情况」：
- 「最好情况」：无扩容、操作在末尾（仅修改成员变量/直接写入）；
- 「最坏情况」：需扩容、操作在开头（涉及数据拷贝/移动）；
- 标注核心为「日常关注的最坏/平均复杂度」，特殊场景备注说明。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `string()`                    | O(1)                   | O(1)     | 仅初始化 `size=0`/`capacity=0`，无内存分配/拷贝                              |
|                    | `string(const char*)`         | O(n)                   | O(n)     | n为C字符串长度，需拷贝所有字符到新内存                                       |
|                    | `string(size_t n, char c)`    | O(n)                   | O(n)     | 分配n个字符空间并填充c，必须遍历n次                                          |
|                    | `operator=`（赋值字符串）     | O(n)                   | O(1)     | n为右侧字符串长度（拷贝数据）；赋值空字符串为O(1)（仅改size）                 |
|                    | `assign()`                    | O(k)                   | O(k)     | k为赋值的字符数（如`assign(n,c)`为O(n)，`assign(str,2)`为O(2)）              |
| 长度与容量操作     | `size()`/`length()`           | O(1)                   | O(1)     | 直接返回成员变量`size`，无计算/遍历                                          |
|                    | `empty()`                     | O(1)                   | O(1)     | 仅判断`size==0`，常数时间                                                    |
|                    | `capacity()`                  | O(1)                   | O(1)     | 直接返回成员变量`capacity`                                                   |
|                    | `reserve(n)`                  | O(m)                   | O(1)     | m为新capacity（n≤当前capacity时O(1)；n>capacity时拷贝原数据，O(原size)）      |
|                    | `shrink_to_fit()`             | O(n)                   | O(n)     | 重新分配`size`大小的内存，拷贝所有字符（n为当前size）                         |
|                    | `clear()`                     | O(1)                   | O(1)     | 仅将`size`置0，不释放内存/移动数据                                           |
| 字符访问           | `operator[]`                  | O(1)                   | O(1)     | 连续数组下标偏移访问，无越界检查                                             |
|                    | `at(size_t pos)`              | O(1)                   | O(1)     | 下标访问+常数时间的越界检查（`pos<size`）                                    |
|                    | `front()`/`back()`            | O(1)                   | O(1)     | 等价于`s[0]`/`s[size-1]`，直接访问首尾元素                                   |
|                    | `data()`/`c_str()`            | O(1)                   | O(1)     | 返回底层数组指针，无拷贝（C++11后保证以`\0`结尾）                            |
| 字符串拼接         | `operator+=`（追加字符）      | O(n)                   | O(1)     | 无扩容O(1)（直接写入末尾）；扩容需拷贝原数据，O(原size)                       |
|                    | `operator+=`（追加字符串）    | O(n+m)                 | O(m)     | n=原长度，m=追加长度；无扩容O(m)（仅拷贝追加部分），扩容O(n+m)                |
|                    | `append()`                    | 同`operator+=`         | 同`operator+=` | 逻辑与`+=`一致（如`append(3,'!')`无扩容O(1)，有扩容O(n)）                    |
|                    | `push_back(char c)`           | O(n)                   | O(1)     | 同「追加单个字符」，无扩容O(1)，扩容O(n)                                      |
| 字符串修改         | `insert(pos, str)`            | O(n+m)                 | O(m)     | n=原长度，m=插入字符串长度；需移动`pos`后字符（O(n)）+拷贝插入字符串（O(m)）；插入末尾无移动O(m) |
|                    | `erase(pos, len)`             | O(n)                   | O(1)     | 需移动`pos+len`后字符（最多O(n)）；删除末尾仅改size，O(1)                    |
|                    | `replace(pos, len, str)`      | O(n)                   | O(m)     | 长度相等时直接覆盖O(m)；长度不等需移动字符O(n)；扩容额外加O(n)               |
|                    | `swap(string& s)`             | O(1)                   | O(1)     | 仅交换`size`/`capacity`/底层指针，无数据拷贝                                 |
|                    | `pop_back()`                  | O(1)                   | O(1)     | 仅将`size-1`，无数据移动/拷贝                                                |
| 查找与匹配         | `find(str, pos=0)`            | O(n*m)                 | O(n)     | 朴素暴力匹配（无KMP优化），n=原串剩余长度，m=查找串长度；首字符不匹配O(n)    |
|                    | `rfind(str, pos=npos)`        | O(n*m)                 | O(n)     | 同`find`，仅遍历方向相反                                                     |
|                    | `find_first_of(str)`          | O(n*k)                 | O(n)     | n=原串长度，k=查找字符集大小；逐个检查字符是否在集合中                       |
|                    | `find_last_of(str)`           | O(n*k)                 | O(n)     | 同`find_first_of`，遍历方向相反                                             |
|                    | `find_first_not_of(str)`      | O(n*k)                 | O(n)     | 同`find_first_of`，检查「不在集合中」的字符                                  |
| 子串提取           | `substr(pos, len)`            | O(len)                 | O(len)   | 拷贝len个字符到新字符串；len默认到末尾则O(n-pos)                              |
| 字符串比较         | `operator==/!=/<`             | O(min(n,m))            | O(1)     | n/m为两串长度，逐字符比较到不同/末尾；首字符不同直接返回O(1)                 |
|                    | `compare(str)`                | O(min(n,m))            | O(1)     | 同`operator`比较，`compare(pos,len,str)`为O(min(len,m))                       |
| 非成员函数         | `operator+`（拼接）           | O(n+m)                 | O(n+m)   | 构造新字符串，拷贝两个字符串的所有字符（n/m为两串长度）                      |
|                    | `getline(cin, s)`             | O(n)                   | O(n)     | n为输入行字符数，读取并拷贝到s                                               |
|                    | `to_string(T val)`            | O(1)                   | O(1)     | 数值位数固定（如int最多10位，long long最多20位），视为常数时间               |
|                    | `stoi()/stol()/stof()`        | O(1)                   | O(1)     | 解析数值位数固定，逐字符处理为常数时间                                       |

### 关键总结
1. **O(1) 操作**：仅访问/修改成员变量（`size`/`capacity`）、末尾操作无扩容（`push_back`/`pop_back`）、`swap`、字符直接访问；
2. **O(n) 操作**：涉及全量数据拷贝/移动（构造、赋值、`erase`/`insert`开头、`shrink_to_fit`）；
3. **O(n*m) 操作**：字符串查找（朴素匹配），仅最坏情况；实际场景中短字符串查找可近似视为O(n)；
4. **扩容影响**：`reserve(n)` 预分配空间可将「扩容导致的O(n)」分摊为O(1)（批量追加/插入时优先调用）。
