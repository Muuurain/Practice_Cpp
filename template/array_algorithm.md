### 前提说明
`std::array` 是**固定大小的连续静态数组容器**，大小为编译期确定的常量，无动态扩容、无容量(`capacity`)概念，内存连续且通常分配于栈上，时间复杂度仅由操作是否遍历全量元素、访问位置决定，无动态内存分配与拷贝开销。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `array()`                     | O(1)                   | O(1)     | 仅初始化静态数组，默认初始化元素，无遍历拷贝                                 |
|                    | `array(initializer_list)`     | O(n)                   | O(n)     | n为容器大小，需拷贝初始化列表内所有元素                                       |
|                    | `operator=`（同大小array）| O(n)                   | O(n)     | 逐元素拷贝赋值，n为容器固定大小                                               |
| 长度与容量操作     | `size()`                      | O(1)                   | O(1)     | 大小为编译期常量，直接返回模板参数值                                          |
|                    | `empty()`                     | O(1)                   | O(1)     | 仅判断`size==0`，常数时间                                                    |
|                    | `max_size()`                  | O(1)                   | O(1)     | 与`size()`完全相同，固定大小容器无上限差异                                    |
| 字符访问           | `operator[]`                  | O(1)                   | O(1)     | 连续内存下标偏移访问，无越界检查                                             |
|                    | `at(size_t pos)`              | O(1)                   | O(1)     | 下标访问+常数时间越界检查                                                    |
|                    | `front()`/`back()`            | O(1)                   | O(1)     | 直接访问首尾元素，无偏移计算                                                 |
|                    | `data()`                      | O(1)                   | O(1)     | 返回底层原生数组指针，无拷贝/遍历                                             |
| 元素修改与填充     | `fill(const T& val)`          | O(n)                   | O(n)     | 遍历所有元素并统一赋值val，n为容器固定大小                                    |
|                    | 单个元素赋值`arr[pos]=val`| O(1)                   | O(1)     | 随机访问直接赋值，无其他开销                                                 |
| 容器交换           | `swap(array& other)`          | O(n)                   | O(n)     | 逐元素交换两个容器内容，无指针优化，必须遍历全量元素                          |
| 容器比较           | `operator==/!=/<`             | O(min(n,m))            | O(1)     | 大小不同直接返回结果(O(1))；大小相同时逐元素比较，至首个不同处                 |
|                    | `compare`逻辑                 | O(min(n,m))            | O(1)     | 与运算符比较规则一致                                                         |
| 非成员函数         | `std::swap(arr1, arr2)`       | O(n)                   | O(n)     | 调用成员`swap`，逐元素交换容器内容                                           |
|                    | `std::get<N>(arr)`            | O(1)                   | O(1)     | 编译期索引访问，常数时间定位元素                                             |
|                    | 范围for遍历`for(auto& x : arr)`| O(n)                   | O(n)     | 遍历容器全部元素，次数等于固定大小n                                           |

### 关键总结
1. **O(1) 操作**：所有元素随机访问、长度获取、判空、编译期索引访问、单个元素赋值，均为常数时间；
2. **O(n) 操作**：构造赋值、整体赋值、`fill`填充、`swap`交换，均需遍历全部固定元素；
3. **核心特性**：无扩容、无插入/删除操作，不支持`push_back`/`insert`/`erase`/`resize`等改变大小的操作；
4. **效率特点**：访问效率与原生数组一致，无额外运行时开销，`swap`无指针优化是与`vector`/`string`的核心区别。
