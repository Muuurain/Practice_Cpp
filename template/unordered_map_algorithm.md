### 前提说明
`std::unordered_map` 底层基于**哈希表（拉链法）**实现，存储**唯一键-值对**，元素无序，时间复杂度由哈希函数质量、哈希冲突决定：
- 「最好/平均情况」：无哈希冲突、无需重哈希，核心操作常数时间；
- 「最坏情况」：哈希冲突严重（退化为链表）、触发重哈希，操作退化为线性时间；
- 标注核心为「日常关注的平均/最坏复杂度」，特殊场景备注说明。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `unordered_map()`             | O(1)                   | O(1)     | 仅初始化哈希桶、size，无内存分配/元素拷贝                                    |
|                    | `unordered_map(const unordered_map& other)` | O(n) | O(n) | 拷贝所有n个键值对，重新计算哈希值插入新哈希表                                 |
|                    | `operator=`（赋值）| O(n)                   | O(n)     | 清空原容器，拷贝赋值对象所有键值对，全量插入哈希表                           |
| 长度与容量操作     | `size()`                      | O(1)                   | O(1)     | 直接返回成员变量元素个数，无计算/遍历                                        |
|                    | `empty()`                     | O(1)                   | O(1)     | 仅判断元素个数是否为0，常数时间                                              |
|                    | `bucket_count()`              | O(1)                   | O(1)     | 直接返回哈希桶数量                                                           |
|                    | `reserve(n)`                  | O(n)                   | O(1)     | 预分配桶数，无需重哈希O(1)；需重哈希时拷贝所有元素O(n)                       |
|                    | `rehash(n)`                   | O(n)                   | O(1)     | 重新指定桶数并重哈希，全量重新计算哈希值O(n)；桶数不变O(1)                   |
|                    | `clear()`                     | O(n)                   | O(n)     | 销毁所有键值对，清空哈希桶                                                  |
| 迭代器操作         | `begin()`/`end()`             | O(1)                   | O(1)     | 直接返回哈希表迭代器，无遍历/计算                                            |
| 元素访问           | `operator[](key)`             | O(n)/O(1)              | O(1)     | 按键哈希查找，键不存在则插入默认值；冲突严重O(n)，平均O(1)                  |
|                    | `at(key)`                     | O(n)/O(1)              | O(1)     | 按键哈希查找+越界检查，键不存在抛异常，复杂度同查找                           |
| 插入元素           | `insert({key, val})`          | O(n)/O(1)              | O(1)     | 哈希定位+插入，冲突/重哈希O(n)，平均无冲突O(1)，键重复不插入                 |
|                    | `emplace(key, val)`           | O(n)/O(1)              | O(1)     | 原地构造键值对，效率更高，复杂度同insert                                     |
| 删除元素           | `erase(key)`                  | O(n)/O(1)              | O(1)     | 按键哈希查找+删除，冲突严重O(n)，平均O(1)                                    |
|                    | `erase(it)`                   | O(1)                   | O(1)     | 迭代器已定位节点，直接删除，常数时间                                         |
|                    | `erase(first, last)`          | O(k)                   | O(k)     | k为删除元素个数，批量删除哈希表节点                                          |
| 查找与统计         | `find(key)`                   | O(n)/O(1)              | O(1)     | 哈希表二分查找键，冲突严重O(n)，平均O(1)                                     |
|                    | `count(key)`                  | O(n)/O(1)              | O(1)     | 查找键是否存在，结果仅为0/1，复杂度同find                                    |
|                    | `contains(key)`(C++20)        | O(n)/O(1)              | O(1)     | 判断键是否存在，简化版count函数                                             |
| 哈希策略           | `load_factor()`               | O(1)                   | O(1)     | 返回负载因子(size/桶数)，常数时间                                            |
|                    | `max_load_factor()`           | O(1)                   | O(1)     | 获取/设置最大负载因子，常数时间                                             |
| 容器操作           | `swap(unordered_map& other)`   | O(1)                   | O(1)     | 仅交换哈希桶、size等成员变量，无元素拷贝/遍历                                |
| 非成员函数         | `swap(um1, um2)`              | O(1)                   | O(1)     | 同成员函数swap，仅交换容器内部指针                                          |
|                    | 范围for遍历                  | O(n)                   | O(n)     | 遍历所有哈希桶和键值对，时间与元素个数成正比                                 |

### 关键总结
1. **O(1) 操作**：获取迭代器、`size`/`empty`、迭代器定位后`erase`、`swap`、哈希参数获取、无冲突访问/插入；
2. **O(1) 平均 / O(n) 最坏**：核心按键增删查（`insert`/`erase`/`find`/`[]`），哈希冲突是唯一性能瓶颈；
3. **O(n) 操作**：构造/赋值/清空/重哈希/全量遍历，需处理所有元素；
4. **核心特性**：**无序、键唯一、平均O(1)高效查询**，依赖哈希函数质量，无顺序保证，不支持有序查找。
