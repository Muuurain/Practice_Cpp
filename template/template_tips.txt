// template_tips

由于精度问题，能用log10()就不要用log();
循环次数大的加法改成乘法更快;
使用（for(auto &i : pri)）, 循环不会遍历在循环内部新添加的元素, 因为begin和end迭代器在循环开始时就已确定。
在对进行过取模运算的表达式进行减法运算时，要注意被减数可能提前进行过取模运算导致算式结果变为负数,此时对于减法表达式可以先加上MOD再对MOD取模
对于排序后的vector容器，使用lower_bound(.begin(), .end(), val) 比使用find(.begin(), .end(), val)查找效率更高，因为前者是二分查找，后者是线性查找。
循环变量的上限尽量使用.size()函数而避免使用具体的数值.
对于for循环，若条件为i >= 0， 则可表示为~i
vec.size() 返回的是 std::size_t 类型（无符号整数，通常是 64 位）
== 的优先级高于 &。if(a[i] & 1 == 0) -> if((a[i] & 1) == 0)
按位异或运算符：^
异或运算具有交换律和结合律
质数定理：小于等于 x的质数个数 π(x)≈ x / lnx。
双向迭代器（it）只能通过it++, it--进行移动，而不能用it += 4等进行移动，如访问第五个元素只能通过auto it = std::next(l.begin(), 4);
vector,list等容器的insert函数为朝前插入
STL 容器的迭代器分类型，迭代器直接 + 数字是随机访问迭代器的专属特权：
    ​vector / string / deque / array（随机访问迭代器） 支持 +n、-n、[] 下标
    list / set / map / multiset（双向迭代器） 只支持 ++、--，不支持加减整数
splice函数执行的是转移操作，而不是复制, 且转移到目标迭代器的前方
若在链表内部的某一部分的某两块执行splice函数交换位置，该部分外的前后元素会自动调整指针指向位置
执行判断语句==时可以将常量写在左边，这样如果不小心漏掉了一个等号，编译器会直接抛出语法错误（因为不能给常量赋值），
BFS 必须“入队即标记”，不能等“出队才标记”，否则队列大小可能会指数级增长
