在现代算法竞赛（C++ 语言环境，评测机通常按 $1\text{ s}$ 约跑 $10^8 \sim 2 \times 10^8$ 次基本运算估算）中，不同数据规模所能承受的最高时间复杂度对应如下：

| 数据规模 ($n$) | 常见最高允许复杂度 | 典型算法与应用场景 |
| --- | --- | --- |
| $n \le 10 \sim 12$ | $O(n!)$ | 全排列枚举、深搜回溯 |
| $n \le 20 \sim 24$ | $O(2^n)$ / $O(n \cdot 2^n)$ | 状态压缩 DP、子集枚举、折半搜索 (Meet-in-the-middle) |
| $n \le 100$ | $O(n^4)$ | 多重循环枚举、高维动态规划 |
| $n \le 400 \sim 500$ | $O(n^3)$ | Floyd 最短路、区间 DP、高斯消元、基础矩阵乘法 |
| $n \le 2000 \sim 5000$ | $O(n^2)$ | 二重循环暴力、背包 DP、二维前缀和 |
| $n \le 10^5 \sim 2 \times 10^5$ | $O(n \sqrt{n})$ / $O(n \log^2 n)$ | 莫队算法、分块、树套树、CDQ 分治 |
| $n \le 5 \times 10^5 \sim 10^6$ | $O(n \log n)$ | 快速排序、线段树 / 树状数组、二分查找、堆优化 Dijkstra |
| $n \le 10^7 \sim 10^8$ | $O(n)$ | 线性筛（欧拉筛）、双指针、单调栈/队列、KMP / AC 自动机 |
| $n \le 10^{12}$ | $O(\sqrt{n})$ | 质数判定、试除法求因子、数论分块 |
| $n \le 10^{18}$ | $O(\log n)$ | 快速幂、二分答案、GCD（辗转相除）、矩阵快速幂优化 DP |
| $n > 10^{18}$ | $O(1)$ | 数学公式推导、找规律、位运算直接计算 |
