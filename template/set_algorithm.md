### 前提说明
`std::set` 底层基于**红黑树（平衡二叉搜索树）**实现，元素**有序且唯一**，无容量`capacity`概念，不支持随机访问，核心操作依托平衡树特性，时间复杂度稳定统一：
- 「最好/平均/最坏情况」：核心增删查操作均为 $O(\log n)$，无显著差异；
- 标注核心为「标准时间复杂度」，特殊场景备注说明。

以下按功能分类，列出每个函数的时间复杂度及核心原因：

| 分类               | 函数/语法                     | 时间复杂度（最坏/平均） | 最好情况 | 核心原因/备注                                                                 |
|--------------------|-------------------------------|------------------------|----------|------------------------------------------------------------------------------|
| 基础构造与赋值     | `set()`                       | O(1)                   | O(1)     | 仅初始化红黑树根节点，无内存分配/元素拷贝                                    |
|                    | `set(const set& other)`       | O(n)                   | O(n)     | 拷贝原set所有n个元素，遍历红黑树并插入新树                                   |
|                    | `operator=`（赋值set）        | O(n)                   | O(n)     | 清空原set，拷贝赋值对象所有元素，全量插入新树                                |
| 长度与容量操作     | `size()`                      | O(1)                   | O(1)     | 直接返回成员变量元素个数，无计算/遍历                                        |
|                    | `empty()`                     | O(1)                   | O(1)     | 仅判断元素个数是否为0，常数时间                                              |
|                    | `clear()`                     | O(n)                   | O(n)     | 销毁红黑树所有n个节点，释放内存                                              |
| 元素访问           | `begin()`/`end()`             | O(1)                   | O(1)     | 直接返回树的迭代器，无遍历/计算                                              |
|                    | `rbegin()`/`rend()`           | O(1)                   | O(1)     | 直接返回反向迭代器，常数时间                                                 |
|                    | 迭代器访问元素                | O(log n)               | O(log n) | 迭代器遍历需沿树节点跳转，无随机访问能力                                     |
| 插入元素           | `insert(val)`                 | O(log n)               | O(log n) | 红黑树查找插入位置+平衡调整，元素已存在则不插入                               |
|                    | `emplace(args)`               | O(log n)               | O(log n) | 原地构造元素，效率高于insert，逻辑与insert一致                               |
|                    | `insert(it, val)`             | O(log n)               | O(1)     | 迭代器为有效位置提示时可优化，最坏仍为树查找平衡                             |
| 删除元素           | `erase(val)`                  | O(log n)               | O(log n) | 按值查找节点+删除+红黑树平衡调整                                             |
|                    | `erase(it)`                   | O(1)                   | O(1)     | 迭代器已定位节点，仅删除+平衡调整，常数时间                                   |
|                    | `erase(first, last)`          | O(k + log n)           | O(k)     | k为删除元素个数，批量删除并调整树平衡                                        |
| 查找与统计         | `find(val)`                   | O(log n)               | O(log n) | 红黑树二分查找目标元素，返回对应迭代器                                       |
|                    | `count(val)`                  | O(log n)               | O(log n) | 查找元素是否存在，set中结果仅为0/1                                           |
|                    | `contains(val)`(C++20)        | O(log n)               | O(log n) | 判断元素是否存在，简化版count函数                                           |
|                    | `lower_bound(val)`            | O(log n)               | O(log n) | 查找第一个≥val的元素，二分查找树节点                                         |
|                    | `upper_bound(val)`            | O(log n)               | O(log n) | 查找第一个>val的元素，二分查找树节点                                         |
|                    | `equal_range(val)`            | O(log n)               | O(log n) | 返回lower/upper_bound迭代器对，set中区间仅含单个元素                         |
| 容器操作           | `swap(set& other)`            | O(1)                   | O(1)     | 仅交换红黑树根节点、size等成员变量，无元素拷贝/遍历                          |
| 非成员函数         | `swap(set1, set2)`            | O(1)                   | O(1)     | 同成员函数swap，仅交换set内部树指针                                          |
|                    | 范围for遍历                  | O(n)                   | O(n)     | 中序遍历红黑树所有节点，输出有序序列                                         |

### 关键总结
1. **O(1) 操作**：获取迭代器、`size`/`empty`、迭代器定位后`erase`、`swap`交换；
2. **O(log n) 操作**：核心增删查（`insert`/`erase`/`find`）、边界查找（`lower_bound`），为set标志性复杂度；
3. **O(n) 操作**：构造/赋值/清空/全量遍历，需处理所有元素；
4. **核心特性**：元素**自动有序、唯一去重**，底层红黑树保证操作稳定高效，不支持随机访问，迭代器插入删除后不失效。
